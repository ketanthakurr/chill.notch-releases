# chill.notch

Turns the MacBook notch into a hub: a file shelf, Now Playing with a colored glow, live activities, window snapping, on-device AI file tools and more.

**Download:** grab the latest `.dmg` from [Releases](https://github.com/ketanthakurr/chill.notch-releases/releases/latest), open it and drag **chill.notch** to Applications. Builds are signed with a Developer ID and notarized by Apple.

Requires macOS 26 or later.

- Website: https://ketanthakurr.github.io/chill.notch-site/
- Bugs and ideas: [open an issue](https://github.com/ketanthakurr/chill.notch-releases/issues/new)

This repository holds releases only; the app's source code is private.
